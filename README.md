# Agent Learning · Stage 1

AI Agent 应用开发学习 · 阶段一：可控生成与工程基础。

## 项目内容

- 大模型 API 调用：对话、流式输出、错误处理与重试
- 结构化输出：JSON 模式、Pydantic 校验、失败自动重试
- FastAPI 服务：健康检查、聊天、文件上传、SSE 流式、文档问答
- 文档解析：PDF（pypdf）与 Word（python-docx）
- 自动化测试：pytest
- CLI 小项目：自然语言 → 结构化待办 → 保存到 todos.json

## 环境要求

- Python 3.11+
- 依赖安装：

pip install -r requirements.txt
